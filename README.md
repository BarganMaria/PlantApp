# 🌿 BloomMoldova — Plant Identification App

Discover the plants around you and learn more about Moldova's biodiversity.

**BloomMoldova** is a Flutter-based mobile application that helps users identify plants using image recognition and explore information about local plant species. It also provides information about endangered plants listed in the **Red Book of Moldova**, helping users become more aware of the country's natural heritage.

## ✨ Features

- **Plant Identification** — Identify plant species using photos and an integrated machine learning model.
- **Red Book Verification** — Check whether an identified plant is included in the Red Book of Moldova and view its conservation status.
- **Plant Catalog** — Browse a collection of plant species with detailed information.
- **Plant Search** — Quickly find plants by their common or scientific names.
- **Favorites** — Save interesting plants for quick access.
- **Identification History** — Keep track of previously identified plants.
- **Watering Reminders** — Set reminders to take care of your plants.
- **Weather Information** — Check weather conditions.
- **Educational Quiz** — Test your knowledge of rare and endangered plants.

## 🛠️ Technologies

- **Flutter & Dart** — Mobile application development.
- **TensorFlow Lite** — On-device machine learning for plant identification.
- **SQLite** — Local database for storing application data and identification history.
- **JSON** — Plant information and species data.
- **Android Studio** — Development and testing environment.

## 🌱 How It Works

1. Take a photo or select an existing image of a plant.
2. The machine learning model analyzes the image and predicts the plant species.
3. View the identification result, including the plant's common and scientific names.
4. Check whether the species is listed in the Red Book of Moldova.
5. Explore additional information about the plant and its conservation status.

## 🎯 Project Goal

The goal of BloomMoldova is to make plant identification more accessible while raising awareness about biodiversity and endangered plant species in Moldova.

The application combines machine learning with educational information to encourage users to discover, recognize, and better understand the local flora.

## 🚀 Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or VS Code
- Android device or emulator

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/plant_identification_app.git
   ```

2. Navigate to the project directory:

   ```bash
   cd plant_identification_app
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```
